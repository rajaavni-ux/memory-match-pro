# memory-match-pro
A high-performance, web-based logic game built with Vanilla JavaScript and CSS3.

Live Demo : https://rajaavni-ux.github.io/memory-match-pro/


## ✨ Features
* **Dynamic Logic:** Custom Fisher-Yates shuffle algorithm for randomized gameplay.
* **Real-time Stats:** Integrated a timer and flip counter using JavaScript `setInterval`.
* **Modern UI:** Responsive dark-mode design with pink accents and CSS Grid layout.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Grid & Flexbox)
* **Logic:** JavaScript (ES6)
* **Tools:** Git, VS Code
